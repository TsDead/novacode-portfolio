# Тесты сайта

Автоматические проверки на Playwright. Запускаются сами на GitHub при каждом изменении в `main`
(вкладка Actions → «Site tests»), а также вручную:

```bash
npm install
npx playwright install chromium   # один раз, скачает браузер
npm test                          # все тесты (компьютер + телефон Pixel 5)
npm run test:mobile               # только телефон
```

Что проверяется:

- **pages.spec.js** — каждая страница грузится без ошибок JS, битых файлов и запросов на сторонние сайты;
  не шире экрана на 320–1920 px; один h1, нет повторяющихся id, у картинок есть alt;
  главная легче 700 КБ, макет не прыгает при загрузке (CLS < 0.1).
- **links.spec.js** — все ссылки и файлы существуют (включая картинки из script.js и их версии для телефона),
  якоря ведут на нужные блоки, sitemap.xml и robots.txt в порядке, на сайте нет форм и сторонних скриптов.
- **home.spec.js** — окно выбора языка, полнота английского перевода, услуги и кнопки «Пример»,
  кейсы, меню (и бургер на телефоне), копирование почты, демо магазина, AI-страница.
- **pages-extra.spec.js** — NFC-метки (анимация, калькулятор, дизайн под бизнес), демо KOMOK
  (бронь, фильтр, «Хочу похожую»), политика конфиденциальности (RU/EN).
