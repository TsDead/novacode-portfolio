# new-coder.ru — памятка для работы с сайтом

Владелец: Степан Бедин (TsDead), бренды NOVACODE и Duallix LLC. Общаемся по-русски.
Контакты на сайте: Telegram @n0vacode, stepchikcrypto@gmail.com.

## Правила

- Коммиты только от имени владельца: `git config user.name "Ts_Dead"`, `user.email "stepchikbedin@gmail.com"`.
  Никаких упоминаний Claude: ни `Co-authored-by`, ни ссылок на сессию в коммитах, PR и файлах.
- Пушить можно сразу в `main`: сайт публикуется GitHub Pages из `main` за пару минут.
  Крупные переделки дизайна сначала показывать на копии (отдельная ветка, скриншоты), `main` не трогать до согласия.
- Перед пушем прогонять тесты: `npm test` (все должны пройти).
- Меняя `style.css` или `script.js`, поднять версию `?v=...` в `index.html` и `ai.html`
  (одинаковую в обоих). Иначе у части посетителей останется старая версия из кэша.
- Сайт не собирает данные: никаких форм, аналитики, cookie, сторонних скриптов и шрифтов
  (так обещает `privacy.html`, это проверяют тесты). Если это меняется — сначала обновить политику.
- Картинки кейсов — WebP: полная 1200 px и лёгкая `имя-640.webp` для телефонов.

## Устройство сайта

Чистые HTML/CSS/JS без сборки. Тёмная тема, золотой акцент `#C9A25B`, шрифты Unbounded (заголовки)
и Onest (текст) лежат в `fonts/`.

- `index.html` — для заказчиков. Первый экран «Боты и сайты для бизнеса» + демо магазина YFB Store в Telegram;
  блок «Что я делаю»: бот для записи — от 3 500 ₽, магазин в Telegram — от 15 000 ₽, сайт/лендинг — от 5 000 ₽,
  NFC-метки — от 1 990 ₽; «Работы» — только клиентские кейсы; карточка «Ищете AI / LLM-инженера?» → `ai.html`.
- Приветственное окно на главной: язык (RU/EN) — только при первом визите, затем вопрос
  «Что вас интересует?» — **при каждом входе**, с крестиком и Esc. Владельцу оно нравится, не убирать.
- `ai.html` — для работодателей: AI / LLM Engineer, 7 AI-проектов, карточка стека.
- `nfc.html` — NFC-метки для отзывов на Яндекс Картах. **QR-код нигде не упоминать.**
  Цена в коде (`BASE_PRICE = 1990`) помечена как «поменяйте на реальные».
- `komok.html` — демо-концепт магазина для канала @komok_resale (Екатеринбург), шрифты свои.
- `privacy.html` — политика конфиденциальности RU/EN.
- `script.js` — тексты EN, данные кейсов (`PROJECTS`), цены, логика; RU-тексты берутся из HTML.
  Страница определяется по `<body data-page="ai">`.
- `tests/` — Playwright (компьютер + Pixel 5), описание в `tests/README.md`; запускаются и на GitHub Actions.
  Служебные файлы исключены из публикации в `_config.yml`.
